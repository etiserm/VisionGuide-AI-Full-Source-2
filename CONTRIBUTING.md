# Contributing

Thanks for taking an interest in VisionGuide AI. Contributions should keep the prototype's experimental status and safety limits clear.

## Before opening a change

- Describe the platform, behavior, and steps to reproduce.
- Keep iOS, Android, and Python differences explicit; they are separate implementations.
- Do not add private data, credentials, or images/recordings without permission to share them.
- For model or dependency changes, document the source, version, and relevant licensing terms.
- Do not add unsupported safety, accuracy, or performance claims.

## Reporting issues

Include device/OS, relevant toolchain, project revision, model artifact, and concise reproduction steps. Remove personal information from logs and screenshots.

## Validation

Run the relevant platform build or manual checks in its native development environment and report what you actually ran. There is no single cross-platform test command at this time.
