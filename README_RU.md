## Запуск

### iOS

1. Откройте [`VisionGuide.xcodeproj`](iOS/VisionGuide-AI-iOS/ios/VisionGuide/VisionGuide.xcodeproj) в Xcode на macOS.
2. Выберите target VisionGuide, настройте Team для подписи, подключите iPhone и запустите приложение.
3. Разрешите доступ к камере.

Скомпилированной Core ML модели в репозитории нет. Следуйте [руководству iOS](iOS/VisionGuide-AI-iOS/ios/README.md), чтобы подготовить её после проверки условий модели. Xcode-проект можно собрать без модели, но для инференса она нужна во время выполнения.

### Android

1. Откройте [`Android/VisionGuide-AI-Android`](Android/VisionGuide-AI-Android) в Android Studio и дождитесь синхронизации Gradle.
2. Установите Android SDK платформы, необходимой проекту (API 36), подключите устройство с Android 8.0/API 26 или новее и запустите приложение.
3. Разрешите доступ к камере.

Подробности — в [руководстве Android](Android/VisionGuide-AI-Android/README.md). ONNX-модели в репозитории нет; она нужна приложению для инференса и готовится по руководству после проверки условий модели.

### Прототип Python (macOS)

```bash
cd PyCharm/VisionGuide-Python
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python live_camera.py
```

Для инференса Python-прототипа нужен checkpoint YOLO с именем, ожидаемым скриптом. Для демонстрации на изображении положите файл по пути `research/gbhjn.jpg` и запустите `python detect.py`; образцы изображений не включены. macOS может запросить разрешение на камеру для терминала или IDE. Python-прототип содержит отдельные экспериментальные компоненты и не совпадает по функциям с мобильными приложениями.
